# Puesta en Producción Segura

Prácticas de automatización de infraestructura realizadas en el módulo de Puesta en Producción Segura.

## Vagrant

Creación y aprovisionamiento automatizado de máquinas virtuales Ubuntu mediante Vagrant y VirtualBox.

## Terraform

Despliegue y aprovisionamiento automatizado de máquinas virtuales en Proxmox mediante Terraform.
